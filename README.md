# 🛍️ Shopcart - E-Commerce Website

A simple and responsive e-commerce website developed using HTML, CSS, and Bootstrap.

## ✨ Features

- Responsive e-commerce homepage
- Navigation bar with shopping categories
- Hero/banner section
- Product category section
- Featured products section
- Bootstrap-based responsive layout
- Clean and user-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5

## 🎯 Project Purpose

This project was developed to practice frontend web development and responsive website design using HTML, CSS, and Bootstrap.
